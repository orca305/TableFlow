# 구현 범위와 요구사항

## 1차 MVP

실제 Spring Boot 엔진을 사용한 XLSX/CSV → 검토·수정 → 컬럼 매핑 → 정규화·검증 → Oracle/MySQL INSERT SQL 또는 XLSX 다운로드 흐름을 구현합니다. 프런트엔드는 Next.js/TypeScript이며 브라우저 메모리에만 작업 상태를 유지합니다.

원본 raw 값과 가공 value를 분리하고 컬럼 ID는 이름과 무관하게 유지합니다. 숫자는 JSON 문자열/BigDecimal로 처리합니다. 표준 오류 응답, 파일·행·열 크기 제한, 압축 해제량 제한, 수식 실행 방지, SQL 이름·리터럴 검증이 적용됩니다.

## 2차 (실제 로컬 OCR 구현 및 검증 완료)

FastAPI OCR, mock/local/external 공급자, 텍스트 PDF와 스캔 PDF/이미지 추출, 타임아웃·장애 처리, OCR 출처·신뢰도 및 사용자 검토를 구현했습니다. 실제 한글·영문 이미지와 스캔 PDF의 로컬 인식 및 기존 ETL 출력까지 검증했습니다. 외부 게이트웨이는 모의 HTTP 테스트만 수행했습니다. 복잡한 레이아웃의 일반 인식 품질까지 검증한 것은 아닙니다.

## MySQL 실제 적재 (추가 승인 범위)

사용자의 추가 요청으로 기존 DB 직접 적재 제외 범위를 변경했습니다. MySQL 기존 InnoDB 테이블의 배치 INSERT, 스키마/값 검사, 전체 트랜잭션·롤백, 영수증 기반 재시도·동시 중복 방지를 구현했습니다. 비밀은 서버에만 유지하며 로컬 워크스페이스에서 명시적으로 동의한 적재만 실행합니다. [실행·검증](database-loading.md)

## 공개 배포

실제 Spring Boot API를 별도 Java 서버에 배포하고 Next.js를 Vercel에 연결합니다. 호스팅·HTTPS·공개 도메인·요청 제한을 설정하고 외부 전체 흐름 검증 후 포트폴리오에 연결합니다. 로컬 테스트를 공개 배포 완료로 간주하지 않습니다.

## 제외

Oracle 직접 적재, 임의 SQL 실행, 테이블 자동 생성/갱신/삭제, 내부 업무 이력 DB, 회원가입, 스케줄러, Spring Batch, 큐/분산 처리, 사용자 권한, 과금, JSON/XML/API 입력은 제외합니다. 적재 중복 방지용 영수증 메타데이터만 대상 DB에 저장합니다.

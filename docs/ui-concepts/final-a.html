DB 이관

원본과 대상을 선택하고, 매핑과 검증을 마치면 이관할 수 있습니다.

처음이신가요? 사용 방법
  1. 1원본 선택첫 번째 카드를 눌러 이관할 DB와 테이블을 선택한 뒤 '원본 확정'을 누릅니다. 연결 목록에 없으면 '신규 연결'를 선택하세요.
  2. 2대상 선택두 번째 카드를 눌러 데이터를 넣을 DB를 선택합니다. 신규 테이블을 생성하거나 기존 테이블에 적재할 수 있습니다.
  3. 3검토세 번째 카드에서 컬럼 매핑을 확인하고 검증 오류를 모두 해결합니다. 오류가 남아 있으면 이관할 수 없습니다.
  4. 4이관'사전 점검'으로 결과를 미리 확인한 뒤 '이관 시작'을 누릅니다. 중단되어도 '재개'로 이어서 진행할 수 있습니다.

원본이 파일(CSV, Excel, PDF, 이미지)이면 위쪽 '파일 변환' 메뉴에서 변환하고 DB에 적재할 수 있습니다.
